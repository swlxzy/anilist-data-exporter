# AniList Data Exporter

Short description.

## Features

- Export anime lists to JSON
- Multiple/custom lists
- User & community scores
- Advanced scores
- Duplicate handling
- AI-friendly output

## Requirements

- Python 3

## Usage

python anilist.py

Enter your AniList username and select the lists to export.

## Output

Exports are saved as JSON under a folder named after the AniList username.
